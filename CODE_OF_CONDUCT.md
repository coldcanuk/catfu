# Code of Conduct

This project keeps it simple.

## The rules

1. **Be cool** — stay respectful, even when you disagree.
2. **Be kind** — people > internet points.
3. **Love humanity** — no hate, harassment, bigotry, or dehumanizing anyone.
4. **Seek greatness** — aim for quality work and honest collaboration.
5. **Be helpful** — share knowledge, review thoughtfully, leave things better than you found them.

## Not cool

Harassment, threats, spam, doxxing, bad-faith pile-ons, or anything that makes this a worse place for humans (or the AIs helping them).

## Enforcement

Maintainers may warn, moderate, or remove contributions and access that break this code. If something crosses a line, open an issue or contact the maintainers privately.

## Scope

Applies to this repository, issues, pull requests, discussions, and related project spaces.

Be cool. Be kind. Build good things.
