# ADR 0006: GPLv3 license

## Status
Accepted

## Context
Open-source foundation; dependency licenses (Unlicense yt-dlp runtime, MIT/Apache/BSD libs) are GPLv3-compatible when yt-dlp remains an external binary.

## Decision
Distribute catfu under GNU GPLv3. Document third-party notices. Do not vendor yt-dlp.

## Consequences
- Derivative works must comply with GPLv3.
- README states users install yt-dlp themselves.
